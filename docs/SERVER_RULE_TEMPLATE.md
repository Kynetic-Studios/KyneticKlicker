# Server Rule Template

External clickers are allowed up to 13 CPS.

Allowed:
- Standalone external clickers
- Mouse software macros
- Clicking assistance that does not modify Minecraft

Not allowed:
- Hacked clients
- Ghost clients
- Injected clients
- ESP / tracers / x-ray
- Reach / aim assist / velocity
- Packet modification
- Any Minecraft client-side cheat module

Staff note:
Allow the clicking behavior, not cheat clients. If a player admits to using a hacked or ghost client, treat that as unauthorized client usage even if they claim only the clicker module is enabled.
